# 教师反馈后的展示与阅读改进方案

目标：让观众先看到发现，再按需探索证据。依据小组提供的教师讨论记录，保留已认可的整体布局、地图及交互；优先降低 M4、M2 的理解成本。课程展示不以图表种类数量为目标。

## 不变的验收边界

沿用 docs/analysis_plan.md。六国焦点、全球参照、完整分母、未知地区上下界、缺失与零区分、数据源与导出字段全部不变。展示筛选不能成为统计分母。M4 到 M5 的显式导入流程保留。图题不能把相关性写成因果，也不能把 RCA 写成技术水平或出口金额倍数。

## M4 先看发现再探索

增加默认“Key findings”展示，与“Full analysis”切换。原热图、国家与世界对照、年份分组条形图、哑铃图、筛选和导出保留在完整分析中。年份对照默认改回熟悉的分组条形图。

1. Compare baskets：以国家分组条形图展示同一固定商品集合。商品名称在前，HS 编码为辅助；引导案例突出车辆及零部件。动态说明中国与墨西哥的份额差别，收入必须写 similar income，不能写 identical。
2. Share and specialization：引导案例仅突出中国电气设备与玩具两种商品，分别用份额和相对世界商品份额两张条形图。两种指标独立数轴；专业化图标出 1× World benchmark。所有数值来自既有计算。标题只有在实际满足大小反转时才陈述反转。
3. Optional change：作为补充展示，固定中国与墨西哥，以双面板分别比较车辆及零部件的 2010、2023 份额和 RCA，RCA 面板直接标出 1× 基准。默认原分组条形图；完整分析保留哑铃图。两个端点不是连续趋势。

自定义条件不再显示预设案例结论；按实际样本绘图，无比较组或数据不足时明确说明。完整分析的点击高亮逻辑不变。关键发现图支持选择商品并进入完整分析核对。

## M2 突出两国的差异

保留散点与相对规模图。把动态结论提升至图上方，用国名和明确的相对比例引导读者。相对规模图比详细数值卡片先出现；散点中的焦点国写全名，全球背景淡化。操作说明收进“如何阅读”折叠区域，单位、对数刻度及匹配条件继续可见。自定义比较不能沿用德国和日本的固定结论。

## M3 明确地图和地区图的分工

地图负责伙伴位置，排名负责份额，地区图负责商品间地区差异。增加独立动态结论标题，根据所选国家、年份、方向和真实地区份额计算。进口必须称来源或供应方，不沿用出口目的地措辞。突出当前焦点国所属地区；未知地区保留，判断仍由上下界限定。伙伴矩阵直接说明“行是焦点经济体，列是伙伴，颜色为行内贸易份额”，不是洲际矩阵。新旧视图切换继续保留。

## 其他模块与演示安排

M0、M1、M5 保持现有主图及分析范围，本轮不作无证据的换图或重排。M4 主演示前两步，第三步可选；全组 8 分钟展示采用各模块最清楚的默认案例，完整探索用于追问。

## 验收

- 新展示与旧图的份额、RCA、年份及导出记录一致；不得修改 analytics 或 data 文件来适配文案。
- 测试引导案例、自定义条件、缺失端点、无匹配对象，以及进口和出口的标题区别。
- 运行现有全套测试与新增展示语义测试。
- 在 Edge 桌面验证 M4 三步、完整分析回切、M2 动态结论、M3 新旧视图及文字可读性。
- 保存实际截图；完成后记录测试结果和剩余限制。实现完成不等同于教师最终评分。

### M4 三步证据补全（2026年11月7日）

三步统一为“问题 → 发现 → 图内证据”。第一步新增当年人均 GDP 实际数值，说明“收入接近”的依据，并保留中国/墨西哥车辆份额比较。第二步同时呈现中国商品份额、世界商品份额及 RCA，说明份额大与相对专业化强是两个问题。第三步主图新增两国两年的 RCA 条形与 1× 参考线，标题中的份额上升和低于基准都可直接核验；各年仍使用各自完整分母。

RCA 简释：商品在该国出口中的份额 ÷ 其在世界出口中的份额；1× 是世界基准，超过 1× 表示出口更集中于该商品。它不是出口金额倍数或质量评分。该说明在第二、三步以及完整分析的 RCA 模式提供。收入缺失不声称相似，缺失年份不填零，自定义条件不继承固定案例结论。

本轮全套 109 项测试通过，覆盖双面板与既有指标逐项一致、缺失收入/年份、自定义状态和展示回调。Edge 已核对三步实际页面、Full analysis、原分组条形图与哑铃图切换，以及新增 RCA 条形点击进入原详情。截图：docs/screenshots/M4_complete_step1.png、M4_complete_step2.png、M4_complete_step3.png。数据文件、分析计算、导出结构及验收标准未改动。该轮核对结束时保留为本地修改。
