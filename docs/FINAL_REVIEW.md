# Trade atlas 演示与验收指南

更新于 2026-11-20。本页记录当前 Dashboard 的默认条件、台上操作及可复核数值。各版本的旧截图、源码审计和测试次数保留在后半部分，供追溯。

## 启动与验证

从包含 `app.py` 的仓库根目录执行。运行需要仓库中的 `data/processed/`、`data/reference/` 和 `assets/`；原始 CEPII 文件只在重建及独立审计时使用。

```bash
python -m pip install -r requirements-lock.txt
python -m unittest discover -s tests
python app.py
```

浏览器打开 http://127.0.0.1:8050 。本轮 166 项自动测试通过，另在本地运行的服务上验证了 M0 切页暂停、M4 默认中墨、M5 导入及拦截过期比较。

## 单人演示路线

演示依据见[飞书 [4] 最终建议稿](https://jcn9kmhc769i.feishu.cn/wiki/FfJcwtj6TiOCkbkDhxQcaDeen3d#MNBrdzAUgoT6fPxBiSGckuPbnlb)。

| 模块 | 操作 | 观众从图上看到什么 |
|---|---|---|
| M0 Overview | 从 1995 年的 Top 10 开始，切换 Six-economy world shares 观察六国轨迹，把年份停在 2023。 | 世界出口金额与各国所占份额回答不同问题。离开 M0 自动暂停，返回时仍是离开时的年份。 |
| M1 Economy | 直接进入 2023、美国、Similar exports、1.25× 的默认比较。 | 德国货物出口额达美国的 82.7%，美国 GDP 却是德国的 6.14 倍。接下来追踪美国出口流向哪里。 |
| M2 Geography | 保持美国、2023、Top 10 by share。先看 All products，再选 HS85，依次点墨西哥和加拿大联动地图与散点。 | 全商品的距离与伙伴份额总体负相关（Spearman ρ 约 −0.30）。使用页面默认的 GeoDist dist 距离时，HS85 中墨西哥较远（3,369 km），出口份额却高于加拿大（18.37% 对 9.74%，加拿大 548 km）。 |
| M3 Trade partners | 默认美国、2023、全部商品出口；再选 Vehicles & parts（HS87），读伙伴排名和 HS85／HS87 地区对照。Reset case 回到美国全商品出口。 | 六国 30 年合计 180 个经济体×年份的全商品观察中，本地区在已知目的地区域中均排第一。美国 HS85 的第一大目的地区是亚洲，HS87 的第一大目的地区是美洲。美国 HS87 出口中，加拿大占 35.58%，墨西哥占 17.18%。一个是目的国排名，一个是地区汇总。 |
| M4 Product structure | 直接进入默认中墨案例。先看 01 Compare structure，再点 02 Test specialization，沿用 HS87。03 为可选的两年比较。 | 从“墨西哥从美国买什么”转到“墨西哥自己出口什么”。2023 年中墨人均 GDP 接近，车辆及零部件占各自商品出口的 5.40% 和 26.12%；电气设备（HS85）的排序相反，中墨份额分别为 31.36% 和 18.05%。回到车辆（HS87），同年 RCA 分别为 0.65× 和 3.14×，1× 为世界基准。 |
| M5 Time change | 直接进入默认 Vehicles & parts，看 Compare recovery，再切 Check structure。保留中墨、2019–2023 和 HS87。 | 2019=100，2023 年中墨 HS87 名义出口金额指数分别为 251.26 和 130.73。同期该章在本国出口中的份额分别从 2.74% 升到 5.40%、从 24.85% 升到 26.12%。金额与份额各有分母。 |

若按演讲者的稿子补充德日比较，可在 M1 固定 2023 年，选德国、Similar GDP、1.25×，确认对照国是日本。该年德国货物出口额约为日本的 2.0 倍。随后选回美国、Similar exports、德国，继续主线。

## 导入与自选分析

普通导航保留各模块的条件。M0–M3 使用本地控件。M4 的 **Use current M3 selection** 和 M5 的 **Use current M4 selection** 用于临时追问或演示改选后的案例。按上表走默认路线可以直接切页，尤其是从 M3 的美国切到 M4 的中墨比较时。两个导入按钮旁的齿轮打开比较设置；M4 的 **Full analysis** 在齿轮内。

M5 只接受与 M4 当前选择一致的已完成结果。若刚改过国家、模式、收入锚点／范围、年份或商品，提示等待时回到 M4，等图更新后再导入。拦截期间保留 M5 当前条件和撤销记录。实际改变设置的导入可在继续编辑前用 **Undo** 撤销。详见 [联动规则](M4_M5_handoff.md)。

## 指标与文档入口

- 六国是焦点经济体，伙伴范围覆盖全球。Top-N 限制列表长度，份额仍用完整分母；M4 的 RCA 使用同年世界份额。金额以名义美元计，RCA 度量相对集中程度。
- 以下资料分别说明[经济规模](M1_README.md)、[地理距离](M2_README.md)、[商品结构](M4_README.md)、[时间变化](M5_README.md)、[数据准备](DATA.md)及[报告证据](REPORT_ADDENDUM.md)。
- 设计讨论稿、教师反馈落实记录、浏览器截图和原始源审计保留当时的条件与结果。演示从上表的默认条件开始。

## 数据交付和重建

- `country_pair_hs2_focus_year.parquet`约25.6MB，包含六国作为出口方或进口方的全部全球伙伴HS2明细，未做Top-N裁切。M2/M3通过同一读取函数使用；完整全球商品表继续供M4/M5计算。
- 全量`country_pair_hs2_year.parquet`及约10GB原始源不进入Git；审核与日常使用不依赖它们。需要全源复查时运行下面命令。
- 地区统一为Africa/America/Asia/Europe/Oceania/Unknown。America为整个美洲；缺坐标和Unknown金额保留分母。
- M5原模块文档保留历史，旧“第三方来源阻塞”描述由本记录替代。

```bash
python scripts/prepare_final_data.py --source-root /path/to/data
python scripts/audit_final_examples.py --source-root /path/to/data
```

[源文件与输出SHA256、逐年核对数量](../data/processed/m5_source_manifest.json)；[M1官方来源核验](M1_source_audit.json)；[M4官方来源核验](M4_source_audit.json)。缺文件明确报错，不自动补模拟结果。
