## 6分钟演示路径

1. **M0**：2023 → 六国长期份额。区分名义金额增长与份额变化。
2. **M1**：中国全商品 → 点击日本 → 墨西哥/HS87。散点为主，地图和排名定位异常伙伴；相关不能推出因果。
3. **M2**：德国/日本2023 → 相似出口额 → 1.5倍阈值。相似GDP不意味着相似出口额。
4. **M3**：中国HS87出口 → 点美国排名 → 进口 → 矩阵。出口与进口金额不同；Top10只限制显示，Unknown与Other含义不同。
5. **M4**：依次点击三个引导步骤。HS85份额较大，但HS95 RCA更高；再看中墨HS87两端变化。
6. **M5**：点击使用当前M4选择 → 疫情 → HS87 → 金融危机。观察金额返回基期后，结构是否也回到原水平。
