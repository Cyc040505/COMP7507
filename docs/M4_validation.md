# M4 验证记录

## 数据和计算

- 输入：566,165 条国家×HS2×年份记录，覆盖 1995–2024，96 个实际商品章。键无重复、关键字段无空值、金额有限且非负，HS2 前导零保留，名称覆盖所有实际章。
- 独立原始重算：逐年读取全部 30 个官方 BACI CSV，按国家字典连接出口代码，六位补零后提取 HS2，与聚合表逐键、逐金额核对；全部通过。误差与文件 SHA256 见 M4_source_audit.json。
- 商品聚合对照 country_year、flow_year，所有年份键与总额一致（容差 2e-12）。每国份额合计 1；同年各商品按出口总额加权的世界平均 RCA 为 1。手工构造 80%/50%=1.6 例子通过。
- 同年 GDP-CAP 与原始 CHELEM 研究期 7,650 个键对应值一致。收入规则只接受有限正数，明确不跨年填补。
- 独立执行 build_m4_data.py，在临时目录重建两个输入；全部贸易键及所有有效 GDP/人口值与附带表一致。重建版限定研究期，并不包含旧表每年一个全空 XXX 占位行；该行从未进入 M4 比较，不构成有效数据损失。

## 自动化

`python -m unittest discover -s tests -v`：六项测试通过，包含已知 RCA、零/缺失/重复、全期真实数据不变量、收入匹配、图表范围，以及真实 Dash HTTP 回调请求。

HTTP 检查包含份额/RCA、收入模式、清空选择、热图点击、详情与 CSV 下载。热图点击同时覆盖带 customdata 和仅 x/y 的事件：部分 Plotly/Dash 组合会省略 clickData 中的 customdata，故以实际 x/y 分类键识别单元格。

## 研究与协作边界

- 分析回应 proposal 的 HS2 份额/RCA 热图及 H3 同收入比较；时间可切换，但事件/恢复不在 M4 重复实现。
- 同收入仅为公开的探索比较规则，没有控制其他混杂因素，不是总体统计假设检验；末期 GDP 估计可能影响同伴选择。
- 无记录不擅自补零，不将小正数四舍五入后显示为真零。全球参照不因所选案例或 Top-N 改变。
- 组长的表现分类与特殊实体处理尚待统一。M4 预留自由选择，不伪造类别、排名类型或因果结论。

## Jeff 反馈后的改进验证

新增回归测试覆盖三步案例、收入候选池与阈值敏感性、2024拒绝收入匹配且不替换年份、保留Overview入口条件、shell单一全局状态写入、展示范围内重新计算发现、缺端点保留未知但世界份额仍可计算、两年各自世界参照、无效基年、两种CSV与隐藏模块保护。自动化共13项通过；原有全期原始审计和数据文件均未改变。

收入匹配窗口的依据和限制记录在 m4_income_policy.json；这是一项保守的年份政策，不是所有单元格均为最终实际观测的认证。2023与2024的差别及历史估计可能性在界面可见。

关键改动只在M4及其分析、样式和文档；shell增加一个验证来源、年份、国家和商品的intent入口，仍由原有唯一回调写global-filters。其他模块代码不改。
