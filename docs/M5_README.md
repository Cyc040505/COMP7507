# M5｜金额恢复与贸易结构变化

更新日期：2026-11-20。本页说明当前交付版本；[界面演进记录](M5_fieldnotes_update.md)保留历史方案，冲突时以本页为准。

## 分析问题

出口金额回到基期时，商品构成与出口目的地是否也回到原来的格局？金额恢复与结构变化分别检验，不把事件前后差异解释为因果。

## 启动

在项目根目录运行 `python app.py`，打开 http://127.0.0.1:8050 ，点击顶部 **M5 Time Change**。项目使用统一入口，不依赖旧的独立启动脚本。

## 页面与交互

- 顶部提供 Analysis year、01 Compare recovery、02 Check structure，以及联动按钮右侧的齿轮（Customize this comparison）。点击齿轮可展开或收起比较设置。控件、字体和蓝灰配色与 M4 对齐。
- 支持美、德、中、墨、荷、意中选择 1–6 国，保持输入顺序。桌面国家卡片三列，四国时两列，窄屏自动换列。
- Compare recovery 保留完整多国折线（基期金额=100），其后为各国关键年份条形及恢复结果。单国折线与图型切换已移除；散点试版已撤回，不在交付中。
- 国家条形比较基期、事件年和查看年，必要时去重并补窗口末年；所有国家共用从零出发的坐标。结果保留相对基期变化、首次已观测返回、最大观察损失、份额及恢复状态。
- Check structure 的问题、标题、指标切换和两张图放在统一白框内。左图为基期与查看年的 100% 堆叠组成条形；右图为从零出发的份额增减图，正值向右、负值向左。
- Product share 显示所选 HS2 与其他商品；Intra-regional partner share 显示已知区域内、已知区域外与地区未知。两年相同时只展示一次，缺失值不补零。
- 区域增减柱长为已知区域内份额差，可能的整体变化区间保留在悬停中。柱形下方重复的方向提示小字已删除。数值加粗，pp 单位使用较小灰字。
- 页底的 **Finding / Implication / Limits** 汇总恢复状态与结构变化，并随条件更新。年度明细、完整恢复状态表、方法及 CSV 下载均可查看。
- 下拉框、折线点、国家条形及组成条形共用查看年份。结构标题和证据比较基期与查看年；恢复摘要和 CSV 的窗口末年字段仍覆盖完整窗口。

## 与 M4 衔接

在 M4 完成比较后，在 M5 的分析工具栏点击 **Use current M4 selection**。导入 M4 实际显示的国家及顺序、当前分析年，以及唯一选中的商品；M4 同时展示多个商品时，沿用其详情图当前高亮的商品。未高亮商品时使用全部商品。

中墨 2023 年 HS87 使用演示窗口 2019–2023。其他 2020–2024 年导入保留 2019 基期、2020 事件年及 2016 年窗口起点。1996–2019 年用导入年的前一年作基期，比较至导入年。1995 年是最早可用年份，作为基期显示，观察窗口延至 1996 年；M5 的 **Analysis year** 仍选中 1995。导入支持六个项目经济体，非法条件或仍在更新的 M4 比较都会保留当前 M5 设置及 Undo 记录。等 M4 更新后可重试。

导入后直接更新国家、商品、窗口和查看年份，两个预设始终可用。点击预设载入其完整默认条件，查看年份切到窗口末年，并清除导入提示。仅切换模块或大分类不重置条件。

## 演示与案例

首屏显示中墨 HS87，窗口为 2019–2023。先看以 2019 为 100 的金额指数，再切 **Check structure** 看商品占比。中国从 2.74% 升至 5.40%，墨西哥从 24.85% 升至 26.12%。

1. **Pandemic recovery** 载入中德墨、HS87、2019 基期、2020 事件年和 2016–2024 观察窗口。
2. **Financial crisis** 载入中德墨、HS87、2007 基期、2008 事件年和 2004–2013 观察窗口。

两个预设默认展示 **Product share**。在 **Check structure** 可切到 **Intra-regional partner share**，悬停查看地区份额变化的上下界。

## 数据与指标

沿用 BACI HS92 V202601（1995–2024）。地区数据已由官方年度双边原始 CSV 重建并逐键核验；先前第三方来源阻塞已解除。运行使用 `data/processed/m5_region_hs2_year.parquet`、国家／商品年度表及 `m5_source_manifest.json`，校验失败停止分析，不回退到模拟数据。整合记录见 [FINAL_REVIEW.md](FINAL_REVIEW.md)。

金额指数=所选产品出口额／基期同范围出口额×100。商品份额分母固定为该国全部商品出口，区域份额分母固定为所选商品全部伙伴出口。未知地区保留在分母中。地区变化下界=查看年下界−基期上界，上界=查看年上界−基期下界，单位为百分点。地区使用项目固定分类，不是自动社群。

恢复必须先在事件年及以后观测到指数低于 100，随后达到 100 才称首次已观测返回。从未低于基期、返回后回落、尚未返回、缺年、无效基期和缺失末年分别标注。名义金额不等于真实数量；两个结构指标不能代表完整商品篮子或伙伴分布已经恢复。

CSV 保留年度金额、指数、商品份额、区域上下界、覆盖率、恢复状态、基期／事件／窗口、查看年与来源哈希，数据值与图表来自同一计算结果。官方地区表的重建入口为 `python scripts/prepare_final_data.py --source-root /path/to/CEPII-data`。
