## 启动
在项目根目录双击 `启动M5.bat`，浏览器自动打开 M5。当前机器已配置独立 `.venv`。关闭运行窗口停止服务。也可执行 `.venv\Scripts\python.exe launch_m5.py`；端口占用时加 `--port 8051`。原有 `python app.py` 仍从 Overview 进入。

## 三分钟演示
1. **Pandemic recovery**：默认 CHN/DEU/MEX，全产品，2019=100，2016–2024。三国2020年均低于基期，首次已观测返回基期均在2021；2024指数约134.0、108.4、129.2。点击2020/2021点，两个图和明细同步高亮年份。
2. **Vehicles & parts**：同一窗口、同一国家组，切HS87。中国首次已观测返回基期为2021，德国与墨西哥为2022。2024指数约280.6、109.3、130.6；相对2019的产品份额分别改变+3.00、+0.15、+0.28个百分点。金额与产品份额回答不同问题；HS87比汽车范围更广。
3. **Financial crisis**：2007=100，2004–2013。首次已观测返回基期为中国2010、德国2011、墨西哥2010。2013金额均高于基期，但区域内份额的观测下界相对2007分别改变+3.26、−7.62、−3.22个百分点。未知地区导致区间不确定，不能仅从下界变化断言区域化。

以上均是当前数据在指定条件下的计算结果，不是因果结论。可修改国家、商品、基期与窗口查找反例，未恢复对象会在状态表中明确列出。

## 课堂演示中的发现和启示

在全产品疫情案例中，三国都在2021年首次观测到出口额回到2019年水平。墨西哥2024年的区域内份额比基期至少高0.73个百分点。中国和德国的地区未知金额允许上升或下降两种情况。相同的金额恢复年份，不能单独说明出口目的地如何变化。

切换到HS87后，中国仍在2021年返回基期，德国与墨西哥则在2022年返回。中国该章占全部商品出口的份额到2024年比2019年高3.00个百分点，是所选三国中绝对变化最大的案例。用户改变条件后，按钮高亮和解释会按实际选择更新。CSV中的区域份额变化下界等于末期下界减基期上界，上界等于末期上界减基期下界，单位为百分点。

## 与 M4 衔接
先在M4选择案例或自选国家、关注商品，再进入M5点击 **Use current M4 selection**。这是一次显式导入，不会改动M4。当前按钮将2020年及以后的M4年份作为疫情分析终点，基期2019；更早年份用M5手动设置。M4最多6国，M5限定六国中最多4国，超出时提示先缩小比较组。导航切换本身不覆盖模块条件。

## 数据与来源
- 国家/商品年度表沿用原项目 BACI HS92 V202601，1995–2024。
- 新下载原始分发文件保存在 `data/sources/m5`，约133MB。它们是公开Parquet聚合分发，不是CEPII官方ZIP；官方连接当次失败。
- 发布来源：<https://github.com/phbelov/world-trade-app/releases/tag/data-v1>，上游为CEPII BACI，Etalab 2.0。没有复用该项目的应用代码。
- 下载文件SHA256与GitHub release资产digest一致；566,165个出口国×HS2×年份键逐键匹配，最大相对误差2.44e-14；国家和全球年度总额一致。870,755个国家对×年份与HS2汇总也逐键一致。
- 这些对账不能独立审计伙伴流向，方法区明确说明第三方分发边界。
- M5运行只需附带的 `data/processed/m5_region_hs2_year.parquet` 和来源清单，无需加载133MB源文件。计算和文件哈希检查失败时停止分析，不回退到演示值。
- 另生成 `country_pair_year.parquet`，可供M1/M3协作使用；未更改其模块代码。

## 指标
金额指数 = 所选产品出口额 / 基期同范围出口额 ×100。产品份额分母固定为该国全部商品，筛选单商品不会变100%。区域内份额分母固定为所选产品全部伙伴金额。未知地区不当成区域外；显示观测下界、可能上界与已知地区覆盖率。未知出口国地区不计算区域份额。地区来自原项目固定分类，不是自动社群。

恢复在事件年起检查，必须先观测到低于100，随后达到100才称返回。曾返回后回落、未观测到返回、从未观测到损失、无效基期和缺失末年分别标注。缺年保留空值并断线，恢复时间为“首次观测”而非精确事件时间。汇总到可见窗口右端点为止，不能通过藏起事件年份误导比较。

CSV包含每年金额、全产品分母、指数、产品份额、区域内/已知地区金额、区域上下界、覆盖率、恢复状态、基期/事件/窗口及来源哈希。表格值与图表来自同一计算结果。

## 课程对齐和解释边界
时序折线保持连续年度顺序、事件和基期参照；两图共用窗口及国家颜色/线型，并通过点击年份关联细节，体现课程的协调多视图与探索。每次筛选动态重算发现，保留反例与局限。没有为凑技术数量增加模型或图型。

名义商品出口不等于实际数量、服务出口或国内增加值。事件前后变化不证明事件因果；单商品和区域内份额只是两个结构指标，不能认定完整产品篮子或全部伙伴分布已“恢复”。当前观察窗口不构成同收入总体检验，收入可比组的构建继续由M4负责。
