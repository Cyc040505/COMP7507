# M5｜金额恢复与贸易结构变化

更新日期：2026-11-09。本页说明当前交付版本；[界面演进记录](M5_fieldnotes_update.md)保留历史方案，冲突时以本页为准。

## 分析问题

出口金额回到基期时，商品构成与出口目的地是否也回到原来的格局？金额恢复与结构变化分别检验，不把事件前后差异解释为因果。

## 启动

在项目根目录运行 `python app.py`，打开 http://127.0.0.1:8050 ，点击顶部 **M5 Time Change**。项目使用统一入口，不依赖旧的独立启动脚本。本机 8051 为工作预览端口，不是线上部署。

## 页面与交互

- 顶部提供 Analysis year、01 Compare recovery、02 Check structure，以及可展开的 Customize this comparison。控件、字体和蓝灰配色与 M4 对齐。
- 支持美、德、中、墨、荷、意中选择 1–6 国，保持输入顺序。桌面国家卡片三列，四国时两列，窄屏自动换列。
- Compare recovery 保留完整多国折线（基期金额=100），其后为各国关键年份条形及恢复结果。单国折线与图型切换已移除；散点试版已撤回，不在交付中。
- 国家条形比较基期、事件年和查看年，必要时去重并补窗口末年；所有国家共用从零出发的坐标。结果保留相对基期变化、首次已观测返回、最大观察损失、份额及恢复状态。
- Check structure 的问题、标题、指标切换和两张图放在统一白框内。左图为基期与查看年的 100% 堆叠组成条形；右图为从零出发的份额增减图，正值向右、负值向左。
- Product share 显示所选 HS2 与其他商品；Intra-regional partner share 显示已知区域内、已知区域外与地区未知。两年相同时只展示一次，缺失值不补零。
- 区域增减柱长为已知区域内份额差，可能的整体变化区间保留在悬停中。柱形下方重复的方向提示小字已删除。数值加粗，pp 单位使用较小灰字。
- 两个部分图后均有 **What the evidence shows**，按 Question / Evidence / Interpretation 三行呈现，并随条件更新。年度明细、完整恢复状态表、方法及 CSV 下载继续保留。
- 下拉框、折线点、国家条形及组成条形共用查看年份。结构标题和证据比较基期与查看年；恢复摘要和 CSV 的窗口末年字段仍覆盖完整窗口。

## 与 M4 衔接

M4 选择国家、年份和商品后，在 M5 点击 **Use current M4 selection**。这是一次显式导入，不修改 M4。2020–2024 年作为疫情窗口终点，基期为 2019；更早事件通过自选控件设置。完整六国、顺序及商品均保留，重复或范围外国家拒绝并保持当前状态。

导入后直接更新国家、商品、窗口和查看年份，三个案例始终可用。点击案例载入其完整默认条件，查看年份切到窗口末年，并清除导入提示。仅切换模块或大分类不重置条件。

## 三分钟演示

1. **Pandemic recovery**：默认中德墨、全产品、2019=100、2016–2024。三国首次已观测返回均为 2021，2024 指数约 134.0、108.4、129.2。点选 2020，再查看恢复结果和结构组成。
2. **Check structure**：区域柱显示已知份额差。中国整体变化区间约 −1.21 至 +3.97 pp，不能据已知份额上升断言整体方向；墨西哥下界为正。金额恢复不保证结构恢复。
3. **Vehicles & parts**：切 HS87，中国首次返回为 2021，德国和墨西哥为 2022。2024 指数约 280.6、109.3、130.6；产品份额较 2019 改变约 +3.00、+0.15、+0.28 pp。
4. **Financial crisis**：2007=100、2004–2013。首次返回分别为中国 2010、德国 2011、墨西哥 2010；区域内已知份额变化约 +3.26、−7.62、−3.22 pp。悬停查看整体变化边界。

## 数据与指标

沿用 BACI HS92 V202601（1995–2024）。地区数据已由官方年度双边原始 CSV 重建并逐键核验；先前第三方来源阻塞已解除。运行使用 `data/processed/m5_region_hs2_year.parquet`、国家／商品年度表及 `m5_source_manifest.json`，校验失败停止分析，不回退到模拟数据。整合记录见 [FINAL_REVIEW.md](FINAL_REVIEW.md)。

金额指数=所选产品出口额／基期同范围出口额×100。商品份额分母固定为该国全部商品出口，区域份额分母固定为所选商品全部伙伴出口。未知地区保留在分母中。地区变化下界=查看年下界−基期上界，上界=查看年上界−基期下界，单位为百分点。地区使用项目固定分类，不是自动社群。

恢复必须先在事件年及以后观测到指数低于 100，随后达到 100 才称首次已观测返回。从未低于基期、返回后回落、尚未返回、缺年、无效基期和缺失末年分别标注。名义金额不等于真实数量；两个结构指标不能代表完整商品篮子或伙伴分布已经恢复。

CSV 保留年度金额、指数、商品份额、区域上下界、覆盖率、恢复状态、基期／事件／窗口、查看年与来源哈希，数据值与图表来自同一计算结果。重建：`python scripts/build_m5_data.py --download`。
