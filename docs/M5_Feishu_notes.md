**M5 金额恢复与贸易结构变化**

围绕“出口金额回到基期时，卖什么、卖给谁是否也回到原来的格局？”展开。默认比较中国、德国、墨西哥，以 2019 年为基期观察 2020 年疫情前后，再切换至 HS87 车辆及零部件，检查同一组国家的恢复年份是否改变。金融危机作为第二个观察窗口。

采用两张按年份对齐的折线图。上图将基期名义出口额设为 100，下图可切换商品出口份额与区域内伙伴份额。点击年份查看两图对应的金额与份额，状态表区分已返回、返回后回落、未观察到返回和资料不足。用户可更换国家、商品及窗口，也可点击按钮带入 M4 的选择，检查默认案例的发现是否仍成立。

使用 BACI HS92 V202601（1995–2024）国家×商品×年份数据，以及已与项目金额核对的同版双边×HS2 汇总。商品份额以该国全部商品出口额为分母，区域内份额以所选商品对全部伙伴的出口额为分母。未知伙伴地区保留在分母中，用上下界判断变化方向。金额按当年美元计，事件前后差异仅作描述性比较。
