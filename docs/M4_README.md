# M4 产品结构模块

已实现份额/RCA 热图、国家/商品选择、同收入比较、点击详情、同年世界参照和 CSV 证据下载。沿用正式 proposal 的国家×商品热图与 RCA 定义，并以收入比较入口回应 H3。保持 M4 ID、layout/register_callbacks 接口和隐藏模块 guard，不修改其他组员模块或全局控制台。

## 运行与复现

在仓库根目录安装 requirements.txt 后运行 `python app.py`，选择 M4。仓库附带两张 M4 聚合输入（合计约 5.4 MB）；无需提交大体积原始数据。新增代码不引入额外依赖。

- `python -m unittest discover -s tests -v`：计算不变量与 Dash HTTP 回调测试。
- `python scripts/verify_m4_sources.py --source-root ../data`：从本地官方原始文件核对 30 年全部商品键及 GDP-CAP，输出质量记录。
- `python scripts/build_m4_data.py --source-root ../data`：单独重建 M4 两张输入。可加 `--output-dir /tmp/m4-rebuilt` 独立验证，不覆盖公共数据。

BACI 表的 value 为千当年美元。GDP-CAP 为当年美元/人，POP 为百万人；M4 收入比较只使用 GDP-CAP，不依赖 GDP/人口的二次换算。当前附带原始聚合 GDP 表包含研究期外年份，模块严格按选中 1995–2024 年查询。重建脚本仅生成研究期。

## 操作与分析范围

- Selected economies：默认 CHN、DEU、USA，可搜索更换为组长最终案例，最多展示六个。未确认的“强势、进步、稳定”标签不写入应用。
- Similar income：按全局焦点国与当年 CHELEM GDP-CAP，选择其 [1/1.5,1.5] 倍范围中对数比值最近的最多六个经济体，包含基准国。明确展示每个同伴的收入；这是探索规则，GDP estimates may apply。每年同伴可能不同，跨年时先核对名单。
- 全局国家进入比较对象；WLD 不当作国家进入比较。在收入模式中 WLD 使用已有有效焦点国、否则 CHN，并在范围栏明确写出实际基准国。
- 全球参照是完整 BACI 输入（含特殊/历史实体）的同年全部商品；不随国家名单、商品、Top-N 或点击改变。元数据只用于展示候选和名称，不先过滤世界金额。
- 商品默认是各比较国 Top 5 的并集。切份额/RCA 不换列；手动选择商品后保留选择。全局商品组采用现有控制台标签的明确映射，不错误把 HS84 当作只含 84。
- M4 主图采用局部 Share/RCA，全球 indicator 在本模块不另行改变度量；非默认时显示解释。Reset 恢复默认国家、商品、Share 和 Selected economies。
- 点击热图同步详情两个选择器；也可通过选择器键盘操作。详情显示该国 Top 8 商品，并加入被检查商品；对照世界份额，不把 Top 8 重新归一化为 100%。
- 缺记录显示未知/无记录，既不擅自补零，也不把缺失国家年份填成上一年。小正数避免四舍五入为零。RCA 色彩范围 0.125–8，取 log2 且以 1 居中；饱和值有明确图例，单元格/hover 保留真实数值。份额色彩在 50% 饱和。

## 2–3 分钟演示路径

1. 使用 2024、CHN/DEU/USA、Share。中国 HS85 约 29.9%，德国 HS87 约 18.3%，美国 HS27 约 18.3%，说明主要出口结构不同。
2. 切到 RCA，同一商品集合保持不变。中国 HS85 的 RCA 约 1.96，而 HS94 约 2.40：最大出口章不一定是相对专业化最强的章。HS85 范围包括多种电气产品，不能称为芯片数据。
3. 点击 DEU×87，核对焦点国、商品选择器、详情与数值一致。德国车辆及零件（不含铁路车辆）份额约 18.3%，RCA 约 2.28。
4. 切到 Similar income。展示同年人均 GDP 的明确区间及实际同伴，再比较结构。此时不声称所有对象仍是组长的重点国家，也不声称控制了地理、人口等其他因素。
5. 如需展示时间差异，手动选 CHN/MEX 后固定产品 85/87，比较 2010 与 2023，下载两年证据；不要用每年自动变化的同收入名单直接当作固定样本。事件归因、恢复研究交由 M5。

## 可引用的已核实结果

2010→2023，在固定 CHN/MEX 对比中，中国 HS87 份额从约 2.08% 增至 5.40%，RCA 从 0.288 增至 0.648；墨西哥 HS87 份额从 17.50% 增至 26.12%，RCA 从 2.421 增至 3.138。这说明同一章可以在两国都增长，但相对专业化仍不同，不能仅因份额上升就断言 RCA 已超过 1。该比较不是相似收入结论，也不是因果解释。

## 限制与组内待办

H3 的证据限于所选国家、收入匹配规则与年份；不是对全球所有国家的统计假设检验。贸易值为名义金额、年度货物贸易，不表示实际数量、服务贸易或本土增加值。再出口、小经济体、价格及汇率均可能影响比较。HS2 粒度较粗，不支持直接推断芯片、具体车型或企业竞争力。

Overview 的 S 前缀过滤会排除有效 SGP、SWE 等代码；本地包含特殊 S19 的 Top10 并集为 14，去掉 S19 为 13。已记录，未修改他人模块；需组内统一对象及特殊实体规则。M4 不捏造国家类型标签，名单确定后仅需更换默认比较对象/演示脚本。
