# M4 出口商品结构与相对专业化

围绕 Jeff 要求的 pattern、finding 和 implication，提供三步引导与自选探索；同时只显示两张互补主图。与正式 proposal 对齐的核心是国家×商品份额/RCA 热图，以及相似收入国家的结构比较（H3）。

## 三步演示

1. **Compare structure**：2023、中国/俄罗斯/墨西哥，按 Overview 的历年 Top10 候选池与中国同年 GDP-CAP 的 [1/1.25,1.25] 倍范围筛选；完整合格名单为三国，不按商品差异进一步挑选。三国人均 GDP 约 $12,509、$13,538、$13,788，主要商品章分别为 HS85、HS27、HS87。查看各国主要商品及本国/世界对照，说明样本中收入接近不足以概括商品结构。
2. **Test specialization**：同一国家组与商品集合，切换 RCA 并定位 RUS×HS31。2023 俄罗斯 HS27 份额 60.94%、RCA 4.25；HS31 份额 3.86%、RCA 8.47。较小份额可以有较高 RCA；不声称 HS31 在所有商品中 RCA 最高，更不据此断言技术优势。
3. **Check change**：固定 CHN/MEX 和同一组商品，详情切到 2010/2023 两年比较，默认检查 HS87。中国份额 2.08%→5.40%、RCA 0.288→0.649；墨西哥份额 17.51%→26.12%、RCA 2.421→3.138。商品份额上升不保证 RCA 超过 1。2010 中墨不是相似收入匹配样本；这是固定案例的两个截面检查，不是逐年趋势或事件归因。

预计 2–3 分钟即可演示三步；每步都有计算产生的 Finding、Implication 和 Limits。完整事件窗口、恢复与连续时间线交给 M5。

- 图二：同一详情卡内切换“本国 vs 世界”和“两年比较”。本国/世界使用当前国家 Top8 章加被检查章；两年比较固定主图商品集合并补入被检查章，按份额变化百分点排序。各年使用各自世界参照，缺端点不补零。
- 案例按钮发布 M4-intent，由 shell 唯一入口更新全局控制台；M4 不直接写 global-filters 或 active-module。首次从非默认 Overview/全局选择进入 M4 时保留国家、年份和商品；显式点击案例才切换到案例条件。
- 高级控制位于 Customize this comparison。收入模式可选择 Overview 候选池或全部具名经济体，以及 1.25/1.5/2 倍范围；最多展示按对数收入比最接近的六个。完整合格名单及 1.25/1.5 敏感性结果在方法区公开。若基准国不在所选池而有有效贸易数据，会明确作为基准国加入候选。
- 用户改变预置条件后显示 Custom exploration，预置叙述不再沿用，按实际展示国家与商品重新计算发现。仅比较全体展示国都有记录的商品，不在已选商品之外寻找“最大差异”。
- 局部 Share/RCA 控制 M4 热图；全局 indicator 不另行改变度量，非默认时提示。全局商品组按现有控制台的真实标签定位相关章（例如 HS84 对应 84/85）。所有份额和 RCA 分母始终来自完整研究数据，而非 TopN、重点国家或点击子集。
- 特殊/历史实体金额保留在 BACI 世界参照中；展示对象按国家元数据匹配，绝不用 S 前缀删除 SGP、SWE 等有效代码。重点国家的“强势/进步/稳定”标签尚待组内确认，应用不伪造这些标签。

## GDP 预测边界

CHELEM V202502 的贸易文件截至 2023，GDP 文件延伸到 2029 且没有逐单元格状态标记。CEPII 说明超出贸易/BOP 末年的 GDP 使用 IMF WEO 估计；其《世界经济2025》表将 2024/2025 增长列为 projections。因此采用保守的历史比较窗口 1995–2023，不用后续 GDP 预测来补齐 BACI 年份。2024 的收入模式明确排除，不自动改用 2023；手动国家的 BACI 分析仍可到 2024。

历史窗口内仍可能有历史估计与修订，不能称所有数值均为最终实际观测。匹配采用 current USD/person，汇率和价格水平可能影响“收入接近”；这是透明的探索规则，不是官方收入组或对其他因素的控制。依据、访问限制及边界记录在 `data/reference/m4_income_policy.json`：官方索引文本可查，直接网页访问当次返回 403，未假称获取了逐单元格观测标记。

## 数据与复现

数据：BACI HS92 V202601，1995–2024，566,165 条国家×HS2×年聚合记录；金额为千当年美元。GDP-CAP 为当年美元/人；HS1992 名称使用 UN Comtrade 官方字典。

- 运行：安装 requirements.txt 后在仓库根目录执行 `python app.py`，选择 M4。两张紧凑输入已附带，不需要原始大文件。
- 测试：`python -m unittest discover -s tests -v`。
- 原始审计：`python scripts/verify_m4_sources.py --source-root ../data`。
- 独立重建：`python scripts/build_m4_data.py --source-root ../data --output-dir /tmp/m4-rebuilt`。

世界出口 = 全部有向流量加总，不重复加进口。无记录不等同零，金额为名义货物贸易而非实际数量、服务贸易或国内增加值。RCA > 1 仅为相对专业化。再出口、规模与商品章粒度均影响解释；HS85 不等同芯片、HS87 不仅汽车、HS27 不仅原油。

两个 CSV 分别对应主热图和详情实际范围，附数据版本、单位、年份、国家、商品、收入规则、GDP-CAP、引导/自选状态和缺失标记。两年视图额外导出两年份额/世界份额/RCA及百分点变化；世界对照视图不输出并未展示的两年变化结果。
