- 当前 `feat/m2-economy` 分支已合入 main `d1844bf` 并解决 M2 页面和样式冲突；通过 94 项测试与 14 组浏览器检查，截图已更新。交付见 [PR #9](https://github.com/Cyc040505/COMP7507/pull/9)。`v1` 标签保留在整合前提交 `e0ff34c`，未移动。

## 参考线拖曳修复

原实现使用绘图区相对坐标形状，在视野变化后额外调用 Plotly.update，导致线条落后于散点。改用与散点同层的原生数据线，由 Plotly 在手势期间同步变换；预留端点覆盖，仅在需要时通过 restyle 延长端点，保留用户视野。自动范围用真实国家范围约束，重置不会被长参考线撑大。

新增浏览器检查在鼠标按住平移和连续滚轮缩放时测量 SVG 线条与理论位置，误差小于 1 像素；普通拖动没有额外重绘，普通缩放没有参考线端点重绘。另验证远距离视野触发延长、重置恢复国家范围，以及原有比较、下载和导航行为。

## PR 反馈：USA 标签裁切与平板宽度

复现条件：1440px、2023、Germany、Similar exports、1.25×。修复前 USA 标签超出绘图区右边缘约 14.8px，数据点仍完整。原来的横轴自动范围上限只留最大 GDP 的 1.5 倍；参考线端点不参与扩大视野时，这段对数范围不足以容纳向右排列的标签。当比较国家为 GDP 最大的经济体时，将右侧范围留白扩大到最大 GDP 的 4 倍（约 0.6 个数量级），不改变数据、筛选或标签内容，也不关闭绘图区裁剪。修复后同条件标签右侧距绘图区边缘约 31.7px。

新增浏览器检查直接测量 USA 文本的 SVG 边界，覆盖 1440px、1280px 与重置视野；保留缩放、参考线、CSV、无匹配和 390px 检查。此次修复验证：23 项 M2 单元测试、15 组浏览器检查通过；此前整合时完整 94 项测试通过。截图见 [相似出口案例](screenshots/M2_similar_exports.png)。

768px 平板问题已复现：页面宽度为 1024px，来自 main 既有的 `body { min-width:1024px; }`；当前 M2 的窄屏例外仅覆盖 600px 及以下。此项作为后续平板适配待办，本次未修改公共布局。390px 检查通过不代表 768px 已适配。
