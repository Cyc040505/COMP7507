# M5 国家卡片界面更新

完成日期：2026-11-08。基于 GitHub `main` 的 `09eacd2`，在本地分支 `ui/m5-fieldnotes` 实施。

## 改动

采用已确认的方案三布局，继续继承原项目的 Avenir Next / Segoe UI 字体、蓝灰色系和固定国家颜色。M0–M4、全局导航、原始数据和分析计算口径均未改动。

- 将恢复过程呈现为国家卡片：检查年份的金额指数、共用纵轴的小多图、首次已观测返回、相对基期的最大观察跌幅、产品或区域份额及完整窗口末年的状态。
- 一至四国按输入顺序呈现；三国并排、四国两列，窄屏自动调整。
- 将原有发现与启示放在独立说明区域，结构图与年度明细保留配对显示。
- 原叠加金额折线图保留在“Overlay country recovery lines”展开区。
- 增加检查年份滑块；点击国家卡片、结构图或叠加图，均使用同一检查年份。
- 对恢复状态表、方法说明和下载区域统一间距与卡片样式；方法分为计算口径、区域不确定性和来源三栏。
- 继续保留全部案例、自定义筛选、M4 显式导入、来源校验、CSV 字段和缺失值。无观测损失及不可比较的值均单独说明。

## 实现边界

`src/m5_portraits.py` 负责把既有计算结果转成卡片；`src/modules/m5_time.py` 负责布局和年份联动；`assets/zzz_m5_fieldnotes.css` 提供只作用于 M5 的样式。没有新增依赖，也没有修改 `src/analytics`、`src/theme.py` 或共享样式文件。

六个焦点国家的图表输入 ID 始终挂载。卡片重新绘制产生空 clickData 时，年份回调返回 no_update，避免重置检查年份或形成更新循环。检查年份只描述当前读数；恢复摘要、跌幅和末年状态仍覆盖完整显示窗口。
