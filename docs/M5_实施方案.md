# M5｜金额恢复与结构变化

2026-11-04。依据正式 proposal 第4页、课程说明第8页、Temporal & Multivariate Data 和 Interaction 讲义、现有 M4 与模块内控制约定。用户已选择 M5 并要求直接完成；本方案先于实现记录范围。待用户自行同步至飞书底部；没有代发群消息。

## 问题与分析路径
疫情后名义出口金额恢复时，产品份额和区域内伙伴份额是否同时回到基期？选国家/产品 → 以基期100比较金额 → 点选年份检查两个结构指标 → 检查首次恢复与末年状态 → 修改国家/产品，寻找反例。疫情2020为主、金融危机2008为补充，默认基期2019/2007。1995–2024可自由探索。

## 选择的方案
仅做金额线容易重复Overview；重复M4两端点比较无法显示中途回落。采用两张对齐时序图：上图名义出口金额指数、下图产品份额和区域内份额（不同线型、同一百分比轴）。辅以恢复状态表、动态发现、CSV和方法说明。最多4国、一个HS2或全部产品，保持可读性。选择年份只高亮，不截断时间线；每个指标注明分母。

## 数据与口径
BACI HS92 V202601为主，国家/商品年度表沿用项目。补充同版本双边×HS2聚合，逐键对账后生成M5专用区域汇总。CEPII官方连接不可用时，可用注明版本的公开Parquet分发，记录URL、下载SHA256、版本及对账误差，不伪称独立读取了官方CSV。地区固定使用项目country_meta，未知地区不归为区域外；显示已知地区覆盖率。

金额=所选产品范围出口；产品份额=该产品/该国全部产品；全部商品时不展示恒100%的产品份额。区域内份额=同地区目的地金额/同产品全部目的地金额。未知地区份额独立记录。无记录不补零、缺年断线。基期缺失或为0不计算指数。恢复=事件年起首次已观测金额达到基期；区分曾恢复后回落、末年恢复、尚未观察到恢复和覆盖不足。年度缺口存在时只能说首次观测达到，不能断言准确恢复时间。名义金额不等于实际数量，事件标记不作因果证明。

## 功能与交付
模块独立控件、两种事件预设、选择窗口与基期、国家比较、HS2选择、图上点击年份联动高亮、完整数据导出、重置、可读错误和缺失状态。支持粘贴明确的国家/产品上下文后应用，不自动修改M4。M4继续负责份额/RCA截面与两端点；M5负责连续路径和恢复。交付源码、测试、数据来源/对账报告、使用说明、精简飞书方案和启动入口。

## 验收
手算案例覆盖100→80→110→90；正确区分曾恢复和末期回落。测试缺失/零基期、未知地区、单产品分母、跨年缺口、空选择、无效窗口、隐藏模块、CSV与图值一致；真实表对账通过；既有M4测试通过；桌面与窄屏浏览器实测。至少两条由数据计算的演示案例，报告限定条件与反例。
