# M2 · Economic scale

实现依据：《实现方案-最终优化版.docx》的 M2 行、第 2 节共同口径，以及第 3 节“做完按这三步交”。本文用于组员复现、模块审查和 PR 交接。

**当前分支：`feat/m2-economy`。上一轮 [PR #9](https://github.com/Cyc040505/COMP7507/pull/9) 已合并；本次精简版另建 PR。`v1` 标签仍指向已发布版本 `e0ff34c`。** 检查证据见 [M2 验收记录](M2_validation.md)。

M2 回答“GDP 相近时出口规模是否也相近，反过来又如何？”。页面使用 GDP—出口额双对数散点、单维度匹配条带和相对规模条形图；筛选、精确金额、读图说明及数据来源默认折叠。商品范围固定为全部货物，贸易伙伴覆盖全球；本模块不提供 HS2 商品筛选。

后续按负责人要求，锚点入口由“六国推荐＋全球锚点选择”收敛为**仅六国锚点**，候选仍来自全球有效经济体；当前背景显示范围见下方精简版说明。单维度匹配规则继续遵守最终方案，不取十字条带交集。缩放和平移、参考线渐深配色与延伸到视野边缘属于呈现优化。提交 PR 时应将锚点入口调整同步给 Lotus；本次没有改写原始 Word 方案。

默认案例金额独立核算如下。页面单位为十亿美元（`$bn`），原表单位换算见下文。

| 2023 指标 | 德国 DEU | 日本 JPN |
|---|---:|---:|
| GDP（十亿美元） | 4,456.081 | 4,212.945 |
| 全部货物出口（十亿美元） | 1,571.538 | 787.819 |
| 出口/GDP | 35.27% | 18.70% |

例如，德国出口/GDP＝`1,571,537,543.2340074 ÷ (4,456,081.017 × 1,000)`＝`0.3526725697`，显示为 **35.27%**。两国 GDP 落在指定窗口内，出口规模仍明显不同；这一发现可作为后续伙伴及商品结构分析的入口，但不能据此判断贸易效率、GDP 贡献或因果关系。

零值、负值、缺失、非有限值和演示数据拒绝通过测试样例检查，不修改真实数据来制造演示。缺少国家年表或 GDP 表时，M2 拒绝共享读取器返回的演示数据，显示错误且不生成发现；没有匹配与没有有效源数据是不同状态。排除数量及原因在页面和导出中可查。

## 操作与默认案例

- 默认 2023、德国锚点、日本参照、相似 GDP、1.25 倍。六国按钮只切换锚点，保留年份和匹配规则。
- 锚点入口合并为一组六国单选按钮（美国、德国、中国、墨西哥、荷兰、意大利），选中状态高亮；页面和下载均拒绝六国之外的锚点。全球有效国家/经济体仍参与背景和匹配，日本可作为比较国。
- 相似 GDP：只按 GDP 匹配；相似出口：只按出口匹配。候选/锚点落在 `[1/factor, factor]` 内，包括边界，排除锚点自身。
- 两档阈值为 1.25 和 1.5。无匹配保持空状态，不自动放宽阈值或换年。
- 比较国下拉框列出完整匹配名单；点击匹配散点可选中比较国。点击背景点不改变匹配条件。
- 原比较国仍合格时保留；不再合格时显示最接近的新匹配，并提示替换。没有候选时清除旧比较卡及结论。
- 散点双对数，两个坐标统一为十亿美元；有 10%、50%、100% 等比率线，使用同一蓝色系由浅到深表示比率递增，图例保留数值。参考线采用原生数据坐标线，与散点同步缩放和平移，并裁剪到绘图区边缘；预留足够长的端点，仅在视野接近端点时延长。自动范围仍由真实国家数据确定，不因参考线长度扩大。垂直/水平阴影分别表示 GDP/出口窗口，不取十字条带交集。
- 显示范围内的背景国家点统一为浅灰色；仅锚点、匹配国家及当前比较国保留强调色。锚点为菱形、比较国为方形，匹配国家以描边突出。
- 支持滚轮缩放、拖动框选放大、工具栏 Pan 平移、双击或 Reset axes 重置。缩放仅改变视野，不改变匹配名单、金额或导出范围；切换比较国和普通导航保留视野，换年/锚点/匹配条件恢复全局视野。
- 两国金额卡片下新增相对规模横条图，分别以锚点 GDP 和出口额为 100，比较国两项指数共用从 0 开始的线性轴；100 虚线表示基准，坐标随较大值扩展，不截断超过 100 的条。差异标签显示相对锚点高／低百分比，出口/GDP 差距单独用百分点说明。无有效比较对象时清除图表。
- 详情区列出匹配名单、排除原因；CSV 包含当前年份完整来源实体、未舍入金额、匹配与选中标志、排除原因、来源及单位，并包含 `gdp_anchor_100`、`exports_anchor_100`、`export_gdp_gap_pp`，供独立复算相对规模与百分点差。

## 数据及范围

运行时复用 `src/data_loader.py` 的 `load_country_year()` 和 `load_gdp_year()`。
需要项目已有的 `data/processed/country_year.parquet` 和 `gdp_year.parquet`。
任何一个退回演示数据时，M2 显示错误且不生成发现。原始大文件只用于独立核验，启动页面不读取它们。

`data/reference/m2_country_codes_V202601.csv` 是用户提供的官方 BACI 国家字典原样副本，
校验脚本检查 SHA256 与原文件一致。该文件为 M2 提供国家名称及实体范围，不修改共享元数据。
不按 ISO3 首字母过滤，不按 ISO2 是否为空过滤（例如 Namibia 的 ISO2 在原字典为空）。
明确排除 BACI 490（Other Asia nes）、697（Europe EFTA nes）、711（SACU）以及字典外实体。

历史范围保守处理：BACI 58 将比利时—卢森堡合并贸易映射为 BEL，
不能直接与 CHELEM BEL GDP 配对；1995–1998 的 BEL 不进入对数图和匹配。
BACI 736 的分拆前苏丹也使用 SDN，1995–2011 的 SDN 暂不与现行疆域 GDP 配对。
界面与 CSV 明示这些排除，未修改共享贸易值、地区分类或原始数据。
Lotus 若提供经核验的历史疆域统一方案，可集中调整此政策。

研究窗口为 1995–2023，不使用 CHELEM 预测年份。
GDP 和贸易均为有限正值才进入图与候选；负值、零、缺失、重复键均有处理。
“来源实体数”是当年 GDP 与贸易表的实体并集；两表均无记录的字典实体不计入分母。

单位换算：

```text
GDP（十亿美元） = GDP-VAL（百万美元） / 1,000
出口（十亿美元） = BACI（千美元） / 1,000,000
出口/GDP = BACI（千美元） / [GDP-VAL（百万美元） × 1,000]
```

出口/GDP 不是贡献率或效率；大于 100% 不自动判错。只分析名义货物贸易，不作因果推断。
