## 定位与问题

承接 Overview 筛选重点经济体，回答：出口表现不同的经济体，卖的商品是否不同？规模大的商品是否也是相对专业化商品？

初版不预设“专业化导致增长”等因果结论。强势、进步、稳定为组长提供的案例标签，可重叠；不是本模块自行定义的国家分类。M4 负责产品结构，M5 负责事件、恢复与跨年结构变化。

核心探索路径：选择年份与 3–6 个经济体 → 份额热图识别大类 → 切换 RCA 检查相对专业化 → 点击单元格查看商品详情与全球参照 → 形成带条件的发现。

## 数据需求与选择

| 优先级 | 输入 | 粒度、字段与用途 |
|---|---|---|
| 必需 | exporter_hs2_year | 年×出口经济体×HS2；year:int、exporter:string、hs2:两位字符串、value:数值。value 为千当年美元；完整全球范围用于份额与 RCA |
| 必需 | country_meta | iso3 唯一，name、region；名称回退到代码，未匹配单列，不因缺名称丢金额 |
| 必需 | HS2 商品字典（待补） | hs2 唯一、英文短名、完整章名、来源、版本；中文名可选。现有 HS6 字典不能用随便一条商品描述代替整个章名 |
| 必需 | 候选案例清单（待组内确定） | country、显示名、候选类型、选择依据；类型可多选，标记版本与维护者 |
| 校验 | country_year、flow_year | 年×国家总额、年度全球总额；核对产品汇总，不作为缩小全球分母的依据 |
| 可派生 | 年度全球商品总额 | 从完整商品聚合表按 year/hs2 求和；不需要另一位组员手工提供 |
| 后续 | gdp_year 与收入比较规则 | year/country/gdp_per_capita；需明确指标、单位、匹配、覆盖、同收入定义 |

首版选择 BACI HS92 V202601、1995–2024、出口视角、HS2、现有 Parquet。CHELEM 分类、人均 GDP 匹配、HS6 下钻后置，不重复建设原始数据管道。

国家选择分两层：计算参照保留全体有效来源记录；展示从组长重点候选中多选 3–6 个。特殊实体按组内统一规则审计，全球参照若排除记录必须公开范围及金额覆盖，并与 Overview 对齐。不能只用重点国家作为世界。

## 指标口径

记 X(c,p,t) 为经济体 c、商品 p、年份 t 的出口金额：

- 出口份额 = X(c,p,t) / Σp X(c,p,t)。
- 全球商品份额 = Σc X(c,p,t) / Σc,p X(c,p,t)。
- RCA = 出口份额 / 全球商品份额；大于 1 表示相对专业化，不表示技术、效率或因果优势。
- Top 3 份额 = 按全商品出口额排序的前三类份额之和，作为辅助结构集中指标；它依赖 HS2 分类粒度。

所有分母在国家展示选择、商品 Top-N 与点击筛选前确定。零分母为缺失，不填零；未出现的国家—商品记录先检查国家年度覆盖，确认采用稀疏表零流量约定后才显示零，否则显示缺失。缺一年则不把相邻年份连成已观测结果。

## 首版图表和交互

1. 主图：经济体×商品热图。年份用全局年份；国家可在 M4 内多选。支持份额/RCA 切换。初始显示所选国家按出口金额各自 Top 5 商品的并集，保证每国主要商品可见；注明其含义，提供搜索和全类别查看。并集和顺序在同年切换指标时保持不变，避免错把换列当作数值变化。
2. 详情图：点击热图单元格后，以该经济体为焦点，显示主要商品出口份额条形图；与同年世界商品份额对照，确保被点击商品即便不是 Top 10 也可见。显示代码、名称、金额、两种份额、RCA 和有效范围。
3. 小型统计区：焦点国前三类合计份额、选中商品份额与 RCA。证据文字随选择更新，不写未经数据支持的强弱判断。

份额用统一顺序色带；RCA 以 1 为有意义的阈值，若长尾严重使用 log2(RCA) 的中心色带，明确图例、截断及零/缺失处理，hover 保留真实 RCA。具体色标在检查分布后决定。

全球 country 控件表示焦点经济体，M4 比较列表不被截成一个国家；焦点国加入比较列表（最多 6 个，超限提示）。WLD 显示世界份额基准，世界 RCA 不作为真实国家案例。国家清空、无数据、选中商品在切年后无记录都要有明确提示。

全局 product 在 M4 仅定位/高亮对应商品，不重新定义份额与 RCA 分母；目前 HS84 等控件值对应多章标签，须先统一值到类别集合的映射。M4 局部指标切换明确主导主图，全局 indicator 在本模块不改变度量，并显示适用范围，避免两个指标控件冲突。上述筛选语义需组内确认。

只读 global-filters 和 active-module，保留 guard_active；新增 ID 使用 M4 前缀，不由模块改写公共状态。点击仅改变 M4 局部选择。

## 案例选择建议

先用 CHN、DEU、USA 做可复现结构对比，之后按组长分类替换/补入 KOR、MEX 等；这些是候选，尚未认定其属于强势/进步/稳定哪一组。

2024 初步数据：CHN HS85 29.9%、HS84 17.5%；DEU HS87 18.3%、HS84 16.7%；USA HS27 18.3%、HS84 14.3%。可据此提出问题，不由一次截面直接推断长期规律。HS85 是电机、电气设备等大类，不能等同于芯片；HS87 也不是仅汽车一项。

## 分阶段计划与验收

以下为工作量估计，不是已承诺进度；待用户确定范围后执行。

| 阶段 | 预计投入 | 交付/验收 |

| C 最小可用 M4 | 4–6 小时 | 热图、局部比较选择、指标切换、点击详情、空结果提示，接入现有 Dash 框架 |

计算验收：份额在完整类别上约为 1；RCA 全球分母不受界面选择影响；切换年份使用同年全球参照；有效值/零值/缺失可区分；RCA>1 不被写成技术优势。运行验收：初始状态、3–6 国比较、重置、年切换、点击非 Top10 商品、缺数据、隐藏模块不重算；小样本人工核算与图中数字一致。视觉验收：实际浏览器截图检查图例、标签、滚动和小窗口可读性。
