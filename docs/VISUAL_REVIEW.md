## 视觉实施方案

- 采用用户预览的分析台风格：浅灰页面 `#F3F6F8`、白色图表面板 `#FFFFFF`、深蓝地图 `#102A3B`、正文 `#192C3D`、青色操作 `#147E8B`、琥珀色选中提示 `#C48C36`。六国既有类别颜色保留；热图量纲与色标范围保留。
- 字体使用系统 Helvetica Neue / Segoe UI / PingFang SC；页标题26–30px、图题16px、正文14px、坐标和辅助说明12–13px；数值使用等宽数字。
- 桌面左侧窄导航稳定定位，取消巨大横幅及悬空导航卡；内容左对齐，最大宽度约1440px。电脑端导航与分析区保持稳定比例。
- M3布局：局部标题 → 控制条 → 全分母统计条 → 深色地图/矩阵（左）＋伙伴排名（右）→ 地区对照（左）＋发现/选择详情（右）→ 按需展开的方法与下载。
- 其他模块使用同一图表字体、白底、轻网格、轴线、说明和控件规范，不把每段文字做成装饰卡片。
- 地图仅改变背景、线/点样式和标注布局，继续使用真实首都坐标、真实方向和金额线宽；不复制预览中的静态数值。保留原地区堆叠图，不擅自换成预览的分组图。
- 键盘焦点、导航选中状态、明确重置入口、点击后伙伴信息及下载反馈服务已有探索任务；无自动轮播、无装饰动画。

方案复核：预览是视觉基准，不是新增功能清单。固定导航、地图与排名贴近、读数和分母可见均服务贸易分析，不添加无关大数字、营销区块或装饰渐变。

## 严格复核后的改进与验收

本轮按课程可视化作品的五个标准复核：问题是否明确、图形是否适合任务、数值与口径是否可追溯、交互是否帮助比较、结论是否超过证据。没有以“图多”作为完成度标准，也没有把视觉好看当成计算正确的证据。
