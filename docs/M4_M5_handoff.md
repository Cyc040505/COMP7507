# M4 商品结构与 M5 时间变化的联动

在 M5 分析工具栏点 **Use current M4 selection** 即可带入比较。仅切换模块会保留各自的筛选。导入实际改变 M5 条件后，可在继续编辑前点 **Undo** 恢复。

| 条件 | M5 的处理 |
|---|---|
| 经济体 | 从 `M4-comparison.data` 读取当前显示的 1–6 个经济体，沿用顺序。空列表、重复或超出项目范围的经济体会触发提示。 |
| 商品 | M4 只选一个 HS2 时优先使用该商品；否则使用详情图当前高亮的 HS2（`M4-inspect.value`）。未高亮时使用全部商品。 |
| 2023 年、中墨、HS87 | 采用首屏演示窗口 2019–2023，保留两国顺序。 |
| 其他 2020–2024 年导入 | 基期 2019，事件年 2020，观察窗口从 2016 年至导入年。 |
| 分析年 1996–2019 | 基期为导入年的前一年，事件年为导入年。窗口从导入年前四年开始，最早为 1995 年。 |
| 分析年 1995 | 分析年和基期均为 1995，事件年为 1996，窗口为 1995–1996。 |

M5 会把已完成比较与 M4 当前年份、商品、模式以及对应的国家列表或收入锚点和倍数核对，并检查待处理的联动详情。若两者不一致，只显示提示，保留 M5 当前条件与 Undo 记录。返回 M4 等图更新后重新导入。默认演示的中墨 HS87 案例直接进入 M5 即可看到。

## 演示核对

1. 在 M4 选择 **02 Test specialization**，核对中国、墨西哥、2023 年及 HS87。
2. 打开 M5，点 **Use current M4 selection**。展开 **Customize this comparison**，核对两国顺序、HS87、2019 基期、2020 事件年及 2019–2023 窗口。
3. 初始条件相同时导入无变化。要验收 **Undo**，先点 **Pandemic recovery**，再导入并撤销；应恢复此前的中德墨、全商品及 2016–2024 窗口。

完整案例和验证记录见 [M5 使用说明](M5_README.md) 和 [M5 验收记录](M5_validation.md)。
