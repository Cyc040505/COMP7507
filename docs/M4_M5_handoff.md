# M4交付与M5接入

本轮只修改M4及其测试/文档，不修改M5、公共读取层、原始数据、导航或Overview。

## 直接接入
M5导入按钮按点击事件读取两个State，不能使用它们作为自动覆盖M5条件的Input：
- `M4-comparison.data`：`countries`为当前真实显示的国家列表，`year`为当前分析年；`products`是热图显示范围，不是待导入商品。
- `M4-inspect.value`：当前选中的单个HS2，两位字符串。

这与现有 `feat/m5-time-change` 分支的读取名称一致。M4默认与三个引导步骤均为中墨，年份2023；选中商品依次为85、95、87。手动选择最多六国，M5接收上限仍是四国。

导入时沿用已定规则：基期2019，事件2020，窗口[2016, M4.year]；不把M4的2010对照年当作M5基期。空列表、超过四国、年份早于2020应拒绝并保留M5原状态。未选商品用TOTAL。导入后M5独立控制，M4不被修改。

## 联调例子
1. M4点 Check change，确认中墨、2023、HS87。
2. 打开M5，点击 Use current M4 selection。
3. 预期中墨、HS87、2019基期、2020事件、2016–2023窗口。
4. 改M5窗口不影响M4；仅导航来回不覆盖选择。

## 本次验证范围
M4单独运行的18项测试通过，包括1995–2024商品→国家→全球金额对账、全球RCA不变量、真实Dash回调、导出及M5读取状态。浏览器检查三个引导步骤和商品高亮。
M5现有分支的导入回调另作隔离兼容性测试；这不等于整个M5页面的最终验收。

2026-11-04隔离验证：将本轮M4代码和测试放入 `origin/feat/m5-time-change` 的临时副本，运行该分支完整测试集，共35项通过（包括M5显式导入HTTP回调、恢复状态、CSV与来源哈希检查）。未修改或推送M5分支。浏览器三个引导步骤、HS87详情高亮均正常，未记录到页面控制台错误。截图见 `screenshots/M4_six_country_change.png`。
